# 3D Minecraft Web (Three.js)

HTML5 / CSS / JavaScript と [Three.js](https://threejs.org/) を使用して作成された、ブラウザ上で動作する3Dボクセルクラフトゲーム（マインクラフト風）です。外部画像ファイルなどの外部依存なし（テクスチャやSEはプロシージャル生成）で単一のHTMLファイルで動作します。

## 🎮 操作方法

| キー / 操作 | アクション |
| :--- | :--- |
| **画面クリック** | ゲーム開始・マウスロック |
| **W, A, S, D** / 矢印キー | 前後左右に移動 |
| **SPACE** | ジャンプ |
| **マウス移動** | 視点回転（一人称FPS視点） |
| **左クリック（押しっぱなし）** | **敵を攻撃！** (またはブロックを掘る。**押している間だけ掘り進み**、ブロックにひびが入る) |
| **右クリック** | ブロックを置く ／ 食べる ／ 道具を使う（弓・盾・バケツ・クワ・種）／ 作業台・チェスト・かまど・ドア・ベッドを使う ／ 松明を持って TNT に点火 |
| **数字キー 1〜8** / **ホイール** | ホットバー（画面下の8枠）の切り替え |
| **E** | 持ち物とクラフトの画面を開く／閉じる（2×2。作業台の近くでは 3×3） |
| **Q** | 手に持っているアイテムを1つ捨てる（**Shift+Q** で全部） |
| **M** | マップを開く／閉じる（行ったことのある場所だけ見える） |
| **ESC** | 一時停止（マウスロック解除） |

## 🌍 ワールド
- 広さは **161×161 ブロック**。地面は地下40mまで続き、最下層には壊せない**岩盤**があります。
- ワールドを作るたびに地形の形が変わります。地形は5種類あります（スタート地点のまわりは草原）。

| 地形 | 特徴 |
| :--- | :--- |
| 🌿 草原 | なだらかな草地。木がところどころに生えている |
| 🌲 森 | 木がたくさん生えていて、木材が集めやすい |
| 🏜️ 砂漠 | 砂とサボテン。**サボテンにさわるとダメージ**。夜はゾンビの代わりにハスクが出る |
| ❄️ 雪原 | 雪ととがった木。湖は凍っている。夜はスケルトンの代わりにストレイが出る |
| ⛰️ 山 | 高い岩山。てっぺんは雪 |

- あちこちに**湖**があります。水の中はゆっくりしか動けず、**スペースを押すと浮かびます**。
- **水は流れます**。バケツの水を置いたり、水の下を掘ったりすると、低い方へ**横に3マスまで**広がって落ちていきます。
  もとの水（源）を取りのぞくと、流れた水は引いていきます。水面はゆっくり波打ちます。
- **水の中にもぐると**、画面が青くぼんやりして、**息（🫧のゲージ）**が減っていきます。
  **約10秒**で息が切れ、そのあとは1.5秒ごとにダメージを受けます。**顔を水の上に出せばすぐ回復**します。
- 🌋 **溶岩（マグマ）**が地下深くにあります（-34m より下の大きな池と、洞窟の中の小さな溶岩だまり）。
  **さわると大ダメージ**。中に落ちるとなかなか出られません（スペースを押し続ければ、なんとか上がれます）。
  溶岩も水と同じようにゆっくり流れ、**水にふれると石になります**。バケツで溶岩をくむこともできます。
- 洞窟には**クモの巣**があり、入ると動きが遅くなります。掘ると**糸**が手に入ります。
- 1段の段差は、歩くだけで自動で上れます。
- **高いところから落ちると痛い**です。3マスより高いところから落ちると、1マスにつきハート半分ぶんのダメージを受けます。
  水の中に落ちたり、はしごにつかまったりすればダメージはありません。
- **マップ**: 画面右上にまわりの地図（赤い点は敵）、M キーでワールド全体の地図が見られます。**行ったことのある場所だけ**が見え、まだ行っていない場所はまっくらです。🏠 はスタート地点です。
- 地下には**洞窟**（曲がりくねったトンネルや広い空洞）があり、地表にいくつも入口が開いています。
- 深く掘るほど貴重な鉱石が見つかります: **石炭** → **鉄** (-6m〜) → **金** (-18m〜) → **ダイヤ** (-28m〜)
- 地下に潜ると暗くなり、手元のたいまつ光で周囲が照らされます。
- 軽く動くように、地形は16×16列ごと（チャンク）に「見えている面」だけをまとめて描き、遠くのチャンクは描きません。

## 🏚️ たまに見つかる建物
ワールドを作るとき、地形に合わせて**7〜12個くらい**の建物がランダムに建ちます（場所は毎回変わります）。
中には**チェスト**があり、中身も毎回変わります。スタート地点の近くには建ちません。

| 建物 | 出る地形 | 中身 |
| :--- | :--- | :--- |
| 🏠 **小屋** | 草原 | ドアと窓のある丸太の家。ベッド・かまど・作業台・チェスト・松明 |
| 🪣 **井戸** | 草原 | 屋根つきの井戸。**底に水**があり、その下にチェストがかくれている |
| 🏚️ **廃屋** | 森 | くずれた石レンガの家。クモの巣だらけ。作業台とチェスト |
| 🔺 **ピラミッド** | 砂漠 | 角が石レンガの大きなピラミッド。中は空どうで、**はしごで地下の宝物庫**へ下りられる（チェスト2つ・お宝あり） |
| ⛄ **かまくら** | 雪原 | 雪のドーム。ベッド・かまど・チェスト |
| 🗼 **見張り塔** | 山 | 石レンガの高い塔。**はしごで屋上**へ上れる。上にチェストと松明 |

## ☀️ 昼と夜
- 1日は5分（昼 約3分 + 夜 約2分）。新しいワールドは朝から始まります。
- 夜になると空が暗くなり、手元のたいまつ光がともります。画面左上に「夜まで / 朝まで」の残り時間が出ます。

## 🐷 動物（おそってきません）
明るい**草の上**にときどき現れます（同時に8匹まで。ミニマップでは**白い点**）。

| 動物 | 落とすもの | とくちょう |
| :--- | :--- | :--- |
| 🐷 **ブタ** | 生肉 ×1〜2 | のんびり歩き回る |
| 🐮 **ウシ** | 生肉 ×2〜3 | いちばん大きい |
| 🐔 **ニワトリ** | 羽根 ×1〜2 | 小さくてすばしっこい。羽根で**矢**が作れます |

- **生肉**はそのまま食べるとハート1個ぶん。**かまどで焼く**と「焼いた肉」（ハート4個ぶん）になります。
- **小麦を手に持つと、動物がついてきます。**
- **小麦を持って動物を右クリック**するとえさをあげられます。**2匹にあげると赤ちゃんが生まれます**。
  赤ちゃんは小さく、しばらくすると大きくなります（小麦をあげると早く育ちます）。
- 動物を倒しても「Kills」は増えません。

## 🧟 敵モブ (Enemies)
| 敵 | 出てくる場所 | 特徴 | 落とすもの |
| :--- | :--- | :--- | :--- |
| **ゾンビ** | 夜の地上・地下 | 両手を伸ばして追いかけてきて殴る | 腐った肉 |
| **クリーパー** | 夜の地上・地下 | 近づくと点滅して大爆発。地形も壊す（倒せば爆発しない） | 火薬（1〜2個） |
| **ハスク** | 砂漠の夜 | ゾンビの仲間。**朝になっても燃えない** | 腐った肉 |
| **クモ** | 夜の地上・地下 | 足が速く、**壁を登って**追いかけてくる。一番よく出る | 糸（1〜3本） |
| **スケルトン** | 夜の地上・地下 | 距離をとって**弓矢で撃ってくる**。壁の向こうからは撃てない | 矢と、石炭か鉄 |
| **ストレイ** | 雪原の夜 | スケルトンの仲間。矢に当たると**少しのあいだ動きが遅くなる** | 矢と、石炭か鉄 |
| **スライム** | 地下だけ | ぴょんぴょん跳ねてくる。大きいスライムは倒すと**小さく分裂** | スライムボール |

- **出てくる場所**: 敵は**暗いところ**にだけ出てきます。
  - **夜の地上**: プレイヤーから少し離れた地表に出現。最初は4体で、4体倒すごとに同時に出てくる敵が1体増えます（最大10体）。
  - **暗い地下**（地面から5m以上もぐった場所）: プレイヤーの近くの洞窟やトンネルに出現。深いほど数が増えます（最大8体）。
  - **昼の地上**には出てきません。朝になると、明るい場所にいる敵は燃えて消えます。
  - **松明の近く（8マス以内）には出てきません。**
- **深いほど強い**: 深い場所で出てきた敵ほど、体力（最大3倍）・攻撃力（最大2倍）・速さが上がり、体が大きく赤っぽくなります。
- 敵も壁や地面にぶつかります。1段の段差はジャンプで越え、クモは壁を登ります。
- 遠く離れた敵や、長いあいだプレイヤーに近づけない敵は消えて、また新しく出てきます。
- **自然回復**: 6秒間ダメージを受けなければ、少しずつハートが回復します。復活直後は3秒間無敵です。

## 🗿 ボス：3体のボス
地下深くに**石レンガのダンジョン**が**3つ**あります。**場所は最初はわかりません**。探検して地上の石レンガのアーチ（入口の階段）を見つけると、マップに印と 🚪 が出ます。

| 順番 | ボス | 深さ | 体力 | とくちょう |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 🗿 ゴーレム | -30m | 300 | パンチ・岩投げ・地面たたき |
| 2 | 🔥 マグマゴーレム | -34m | 450 | 動きも攻撃も速く、投げる岩が痛い（ダメージ 8） |
| 3 | 💀 やみのゴーレム | -38m | 650 | いちばん強い。**仲間（ゾンビ・クモ・スケルトン）を呼ぶ**。**水が効かない** |

- **順番に目を覚まします**。前のボスを倒すまで、次のボスは眠ったままです（部屋に入ると「まだ眠っている」と出ます）。
- **前のボスを倒すと、次のボスの部屋がマップに出ます**。遠くまで探しに行かなくても場所がわかります。
- どのボスも共通のたたかい方:
  - 近づくと**パンチ**。遠くにいると**岩を投げて**きます。
  - 腕を振り上げたら**地面たたき**。広がる衝撃波は**ジャンプでよけられます**。
  - 体力が半分を切ると怒って速くなります。
  - 🔴 **背中の光るコア**: ボスは**ゆっくりしか振り向けません**。まわりこんで**背中から攻撃すると、ダメージが3倍**になります。
  - 💧 **水**: **バケツの水**をかけると（足元に水を置くと）5秒間しびれて、動きがにぶくなり、**岩を投げられなくなり、地面たたきもできなくなります**。ぬれているあいだは、受けるダメージも1.5倍です。
    ただし **やみのゴーレムに水は効きません**（コアだけがたよりです）。
- 倒すと、その部屋の**宝箱**が開きます。

| ボス | 宝箱の中身 |
| :--- | :--- |
| 🗿 ゴーレム | **ゴーレムの剣**（攻撃 20）・ダイヤ×5・金のりんご×2・鉄×8 |
| 🔥 マグマゴーレム | **マグマの剣**（攻撃 26）・ダイヤ×8・金のりんご×3・鉄のよろい |
| 💀 やみのゴーレム | **やみの剣**（攻撃 34）・**やみのよろい**（ダメージ -65%）・ダイヤ×12・金のりんご×4 |

- 途中で倒されたら、ボスは眠りにもどります（もう一度部屋に入ると再挑戦）。

## ⚔️ 戦闘
- **ハートゲージ (HP)**: 画面下に10個のハート（20HP）。
- **武器**: 素手は攻撃 3。剣を**手に持つ**と強くなります（木 5・石 7・鉄 10・ダイヤ 14）。
- **防具**: 鉄のよろい（ダメージ -30%）、ダイヤのよろい（-50%）、やみのよろい（-65%）。**持ち物のどこかに持っていれば**効果があります。

## 🎒 持ち物とカバン
- 持ち物は**最初は空っぽ**です。ブロックを掘ると持ち物に入り、右クリックで置くと1個減ります。1枠に99個まで。
- 画面下の**ホットバー（8枠）**に加えて、**カバン（16枠）**があります。**大きなカバン**（糸×8）を作ると32枠に増えます。
- E キーの画面で、アイテムを**クリックでつかみ、別の枠をクリックで置きます**（右クリックだと半分つかむ／1個置く）。
- いらないアイテムは、つかんで**ゴミ箱**に置くと消えます。**Q キー**なら地面に落とせて、近づくとまた拾えます。
  道具を落としたときは、**耐久（残り回数）もそのまま**です（拾い直しても新品にはなりません）。
- 地面に落ちているアイテムは、近づくと**入るぶんだけ**拾います。**持ち物がいっぱいのときは拾えません**（そのときは「🎒 持ち物がいっぱい！」と画面に出ます）。
- **チェスト**を置いて右クリックすると、24枠ぶんアイテムをしまえます（壊すと中身がその場に落ちます）。
- **ツルハシ**: 石や鉱石を掘るのに必要です。**手に持っている（ホットバーで選んでいる）ときだけ効きます**。**良いツルハシほど速く掘れます**。
  手に持っていないと減りません。持っているのに掘れないときは、数字キーでツルハシの枠を選びましょう。

| 掘りたいもの | 必要なツルハシ |
| :--- | :--- |
| 草・土・木材・葉・ガラス・作業台・松明・砂・雪・氷・サボテン・クモの巣 | いらない（素手でOK） |
| 石・石炭・レンガ・石レンガ | 木のツルハシ |
| 鉄 | 石のツルハシ |
| 金・ダイヤ | 鉄のツルハシ |

### ⛏️ 掘るのにかかる時間
- ブロックは**左クリックを押している間だけ**掘り進みます。途中で離したり、別のブロックを見たりすると最初からです。
- かたいブロックほど時間がかかり、**良いツルハシを手に持っているほど速く**なります（素手だと石は掘れません）。掘っている途中で持ちかえても速さが変わります。
- 掘っているブロックには、**だんだん深くなるひび**が入るので、あとどれくらいかが分かります。
- 草むらや花、松明などはすぐ取れます。

### 🔧 道具の耐久（使うと減る・壊れる）
- ツルハシ・剣・クワ・弓・盾・よろいは、**使うたびに残りが減り、0になると壊れてなくなります**。
  持ち物の枠に出る**細いバー**（緑→黄→赤）が残りです。残り10回になると画面で知らせます。

| 道具 | 使える回数 |
| :--- | :--- |
| 木のツルハシ / 木の剣 | 60 |
| 石のツルハシ / 石の剣 | 130 |
| 鉄のツルハシ / 鉄の剣 | 260 |
| ダイヤの剣 | 800 ／ ゴーレムの剣 1000 ／ マグマの剣 1200 ／ やみの剣 1600 |
| 鉄のよろい 200 ／ ダイヤのよろい 500 | ダメージを受けるたびに減る |
| 弓 200 ／ 盾 180 ／ クワ 80 | 使うたびに減る |

- **修理**: クラフトのマスに**同じ道具を2つ**並べると、残りを合わせて1つに直せます（少しおまけつき）。

- **食べ物**: 右クリックで食べると回復します。りんご（ハート2個分。葉を掘るとたまに出る）、腐った肉（ハート1.5個分）、焼いた肉（ハート4個分）、パン（ハート3個分）、金のりんご（全回復）。
- **松明**: 置くとまわりが明るくなり、近くに敵が出なくなります。

## 🛠️ クラフト（3×3 のマスに並べる）
- E キーの画面で、材料を**マスに並べる形**によって、できるものが変わります（マインクラフトと同じです）。左右反対に並べてもOK。
- ふだんは **2×2** のマス。**作業台の近く**（または作業台を右クリック）では **3×3** のマスが使えます。
- 並べると右の枠にできるものが出るので、**クリックすると作れます**。
- **📖 レシピ本**: 材料を一度でも手に入れると、その作り方が載ります。カードをクリックすると、持ち物から材料を自動で並べてくれます。
- **まとめて作る**: できあがりの枠を **Shift ＋ クリック**すると、材料がなくなるまで続けて作ります。
  レシピ本のカードも **Shift ＋ クリック**で、作れるだけ材料を並べてくれます（木の板を40枚、などが一度でできます）。

### 🏭 かまど
- かまどを右クリックして、**焼くもの**と**燃料**（石炭・木炭・原木・木の板・棒）を入れると、少しずつ焼けます。画面を閉じても焼き続けます。
- 砂 → ガラス、原木 → 木炭、腐った肉 → 焼いた肉、**生肉 → 焼いた肉**

### 🌾 農業
- 草原や森の**草むら**を掘ると、ときどき**種**が出ます。
- **クワ**で草や土を右クリックして耕し、種を植えると**小麦**が育ちます（近くに水があると早い）。実った小麦を掘ると小麦と種が手に入ります。
- 葉っぱを掘ると、ときどき**苗**が出ます。草や土に植えると、しばらくして木になります。

### 🏠 建物と道具
- **木の板**・**色つきブロック**（6色）・**はしご**（前に進むかスペースで登る）・**ドア**（右クリックで開け閉め）・**ランプ**（明るく、近くに敵が出ない）
- **弓**: 手に持って右クリックで矢を撃つ。**盾**: 手に持って右クリックを押しているあいだ、ダメージを大きく減らす
- **バケツ**: 水や**溶岩**をくんで、別の場所に置ける（溶岩を運ぶときは足元に気をつけて）。**TNT**: 置いて、松明を持って右クリックすると3秒後に爆発
- **ベッド**: 右クリックで復活地点になる。夜に使うと朝まで眠れる（近くに敵がいると眠れない）
- 草原や森には**花**も咲いていて、染料の材料になります。

## 💾 セーブ
- ブラウザ（localStorage）に自動保存されます: **ESCで一時停止したとき**、**30秒ごと**、**ページを閉じるとき**。
- 一時停止画面の「💾 セーブ」ボタンで手動セーブ、「🆕 新しいワールド」でセーブを消して新しい地形から始められます。
- 保存されるもの: 地形（シード＋掘った/置いたブロック）、位置と向き、体力、持ち物（カバンの大きさも）、チェストとかまどの中身、流れている水、行ったことのある場所、見つけたダンジョン、ベッドの復活地点、撃破数、最深記録、時刻（昼/夜）、どのボスを倒したか・どの宝箱を開けたか。敵と、地面に落ちているアイテムは保存されません。
- 草花とクラフトの仕組みを追加したときにセーブの形式が変わったので、それより前のセーブは読み込まれません。
- テスト用に、URL の最後に `?debug` を付けるとブラウザのコンソールから `game` でゲームの中身を触れます。
