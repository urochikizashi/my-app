# 3D Minecraft Web (Three.js)

HTML5 / CSS / JavaScript と [Three.js](https://threejs.org/) を使用して作成された、ブラウザ上で動作する3Dボクセルクラフトゲーム（マインクラフト風）です。外部画像ファイルなどの外部依存なし（テクスチャやSEはプロシージャル生成）で単一のHTMLファイルで動作します。

## 🎮 操作方法

| キー / 操作 | アクション |
| :--- | :--- |
| **画面クリック** | ゲーム開始・マウスロック |
| **W, A, S, D** / 矢印キー | 前後左右に移動 |
| **SPACE** | ジャンプ |
| **マウス移動** | 視点回転（一人称FPS視点） |
| **左クリック（押しっぱなし）** | **敵を攻撃！** (またはブロックを掘る。**押している間だけ掘り進み**、ブロックにひびが入る) |
| **右クリック** | ブロックを置く ／ 食べる ／ 道具を使う（弓・盾・バケツ・クワ・種）／ 三叉の槍を投げる ／ 作業台・チェスト・かまど・醸造台・ドア・ベッドを使う ／ ガラスのビンで水をくむ ／ ポーションを飲む ／ 松明を持って TNT に点火 |
| **数字キー 1〜8** / **ホイール** | ホットバー（画面下の8枠）の切り替え |
| **E** | 持ち物とクラフトの画面を開く／閉じる（2×2。作業台の近くでは 3×3） |
| **Q** | 手に持っているアイテムを1つ捨てる（**Shift+Q** で全部） |
| **M** | マップを開く／閉じる（行ったことのある場所だけ見える） |
| **L** | 実績と図鑑を開く／閉じる（一時停止画面の「📖 実績と図鑑」ボタンでも開ける） |
| **ESC** | 一時停止（マウスロック解除） |

## 🌍 ワールド
- 広さは **513×513 ブロック**。まん中の 321×321 が「もとからの陸地」で、そのまわりに**外の陸地と浜辺、さらに外に海**が広がっています。
  前からあるワールドも、まん中はそのままで、まわりに外の陸地と海が足されます（161×161 のワールドは 353×353 になります）。地面は地下40mまで続き、最下層には壊せない**岩盤**があります。
- ワールドを作るたびに地形の形が変わります。地形は5種類あります（スタート地点のまわりは草原）。

| 地形 | 特徴 |
| :--- | :--- |
| 🌿 草原 | なだらかな草地。木がところどころに生えている |
| 🌲 森 | 木がたくさん生えていて、木材が集めやすい |
| 🏜️ 砂漠 | 砂とサボテン。**サボテンにさわるとダメージ**。夜はゾンビの代わりにハスクが出る |
| ❄️ 雪原 | 雪ととがった木。湖は凍っている。夜はスケルトンの代わりにストレイが出る |
| ⛰️ 山 | 高い岩山。てっぺんは雪 |
| 🏖️ 浜辺 | 外の陸地と海のさかい目の砂浜 |
| 🌊 海 | ワールドのいちばん外がわ。岸の近くは浅く、沖に出るほど深い（最大 20 マスくらい）。ところどころに島がある |

### 🌊 海
- **海の底**には砂と砂利。**海草**や、背の高い**昆布**がゆらゆら生えています（昆布を掘ると手に入り、かまどで焼くと**干し昆布**＝食べ物になります）。
- あたたかくて浅い海には、ピンク・オレンジ・むらさきの**さんご礁**があります（掘ると、さんごのブロックが手に入ります）。寒い海には氷がうかんでいます。
- ⚓ **沈没船**が海の底にしずんでいます。船首と船尾にチェストがあり、金・エメラルド・ダイヤ・**水中呼吸のポーション**などが入っています。中に入るとマップに印がつきます。
- **海の底の下も掘れます**。海の下は、陸の下より鉱石が少し多めです（エメラルドも出ます）。穴をあけると水が流れこんでくるので、息に気をつけましょう。
- 🐟 **海の生き物**: 魚（むれで泳ぐ。生の魚→かまどで**焼き魚**）、🦑 イカ（深い海。**イカスミ**＝黒の染料）。どちらもおそってきません。
- 🧟 **ドラウンド**: 夜の海の底に出る、おぼれたゾンビ。**水の中をすいすい泳いで**おそってきます。ごくまれに**三叉の槍**を落とします。
- 🔱 **海底神殿**: 沖の深い海の底にある、プリズマリンの大きな神殿（ワールドに 2 つ）。中は水で、シーランタンが光っています。
  入ると**海の番人**がやってきます。番人は目から**2 秒ためたビーム**を撃ってきます（細い線が見えたら、柱のかげにかくれよう）。
  大広間の天井の穴から上の**宝の部屋**へ上がると、宝箱に**三叉の槍**（水の中だと 1.5 倍の力）と**海のハート**（食べると 10 分、水中呼吸＋暗視）が必ず入っています。
  1 階は、入口から入っても**まん中の部屋にすぐには入れません**。通路をぐるっと回って、内がわの壁の入口をさがそう。すみには小部屋が 4 つ（宝箱つき）。
- 🌀 **神殿の地下**: まん中の部屋の床のたて穴から、**地下の迷路**に下りられます。迷路のいちばん奥の床の穴の下が、**地下の大広間**です。
  - 👁️ 最初の神殿の大広間には、ボスの**長老の番人**（体力 900）が住んでいます。目から**ためビーム**（線が黄色くなったら向きが決まるので、横に動くか柱のかげへ）、
    近くにいると**採掘低下ののろい**（掘るのがとてもおそくなる）、海の番人を呼びます。**第 2 形態でトゲ**（トゲが出ているあいだに近くでなぐると痛い。槍を投げよう）、
    **最終形態でビーム 3 本とうず潮**（引きこまれる）。たおすと宝箱に **🔱 海王の三叉槍**（攻撃 20・忠誠Ⅲ・水生特効Ⅲ）と、**召雷**・**激流Ⅲ**の本。
  - もう 1 つの神殿の大広間は、ボスのいない宝物庫です。
- 🔱 **三叉の槍を投げる**: 手に持って**右クリックで投げる**と、まっすぐ飛んで当たった敵にダメージ。飛んでいるあいだ、持ち物の枠は**うすく**なって使えません。
  地面にささった槍は、近づくと拾えます（セーブしたり倒れたりしても、槍はなくなりません）。槍を**手に持っているだけで、水の中を速く泳げます**。
- 番人が落とす**プリズマリンのかけら**から、プリズマリン・プリズマリンレンガ・ダークプリズマリン（かけら 8＋イカスミ）・シーランタン（かけら 4＋ランプ）が作れます。
- 長くもぐるときは**水中呼吸のポーション**が便利です。水の中は少し先までしか見えません（暗視のポーションを飲むと遠くまで見えます）。
- 外の陸地にも、まん中と同じように木や建物・洞窟があります。いちばん外は「世界の果て」で、そこから先へは進めません。

- あちこちに**湖**があります。水の中はゆっくりしか動けず、**スペースを押すと浮かびます**。
- **水は流れます**。バケツの水を置いたり、水の下を掘ったりすると、低い方へ**横に3マスまで**広がって落ちていきます。
  もとの水（源）を取りのぞくと、流れた水は引いていきます。水面はゆっくり波打ちます。
- **水の中にもぐると**、画面が青くぼんやりして、**息（🫧のゲージ）**が減っていきます。
  **約10秒**で息が切れ、そのあとは1.5秒ごとにダメージを受けます。**顔を水の上に出せばすぐ回復**します。
- 🌋 **溶岩（マグマ）**が地下深くにあります（-34m より下の大きな池と、洞窟の中の小さな溶岩だまり）。
  **さわると大ダメージ**。中に落ちるとなかなか出られません（スペースを押し続ければ、なんとか上がれます）。
  溶岩も水と同じようにゆっくり流れ、**水にふれると固まります**。流れている溶岩は石に、**溶岩の源（もとの溶岩）は黒曜石**になります。
  バケツの水を溶岩に直接かけても固まります。バケツで溶岩をくむこともできます。
- 🟪 **黒曜石**は、とてもかたい黒むらさきのブロックです。**ダイヤのツルハシでしか掘れません**（約4秒かかります）。**ばくはつでもこわれません**（TNT やクリーパーでゲートがこわれない）。
- 洞窟には**クモの巣**があり、入ると動きが遅くなります。掘ると**糸**が手に入ります。
- 1段の段差は、歩くだけで自動で上れます。
- **高いところから落ちると痛い**です。3マスより高いところから落ちると、1マスにつきハート半分ぶんのダメージを受けます。
  水の中に落ちたり、はしごにつかまったりすればダメージはありません。
- **マップ**: 画面右上にまわりの地図（赤い点は敵）、M キーでワールド全体の地図が見られます。**行ったことのある場所だけ**が見え、まだ行っていない場所はまっくらです。🏠 はスタート地点です。
- 地下には**洞窟**（曲がりくねったトンネルや広い空洞）があり、地表にいくつも入口が開いています。
- 🕳️ **大洞窟**: 地下深く（-18〜-38 m）に、とても広い空洞がいくつもあります（ワールド全体で 14 こくらい。161×161 のワールドでは 8 こくらい）。
  天井から**鍾乳石**が下がり、床から石筍が生え、かべには光る**紫水晶**（かけら 4 つで紫水晶のブロック）や鉄・金・ダイヤが見えています。
  底には**地底湖**（深い所では**溶岩の池**）。まわりの洞窟とトンネルでつながっています。中に入るとマップに印がつきます。
- 🏞️ **渓谷**: 地表から地下深くまで細長く切れこんだ谷があちこちにあります。落ちないように気をつけて（かべに鉱石が見えています）。
- 前からあるワールドにも、大洞窟と渓谷が足されます。ダンジョン・遺跡・建物・村や、**自分で掘ったり建てたりした場所のまわりには作られない**ので、家がこわれることはありません。
- 深く掘るほど貴重な鉱石が見つかります: **石炭** → **鉄** (-6m〜) → **金** (-18m〜) → **ダイヤ** (-28m〜)
- 地下に潜ると暗くなり、手元のたいまつ光で周囲が照らされます。
- 軽く動くように、地形は16×16列ごと（チャンク）に「見えている面」だけをまとめて描き、遠くのチャンクは描きません。

## 🏘️ 村と村人との交易
**草原に村**があります（161×161 のワールドに 1 つ、321×321 では 1〜2 つ）。まん中に**鐘**、そのまわりに**家が 4〜6 軒**、**土の道**と**畑**があります。
中に入ると「村を見つけた！」と出て、**マップに 🏘️ の印**がつきます。

- 家 1 軒に**村人**が 1 人住んでいます。おそってきません。服の色で**職業**がわかります。
- 村人を**右クリック**すると**交換の画面**が開きます。ボタンをクリックで 1 回、**Shift＋クリックで 10 回まで**交換できます。
- お金は **💚 エメラルド**。いらない物を村人に**売る**とたまります。**エメラルドの鉱石**（鉄のツルハシで掘れる）は**山の中**に多く、深い地下にも少しあります。

| 職業 | 服 | 買ってくれる物（→ エメラルド） | 売ってくれる物 |
| :--- | :--- | :--- | :--- |
| 👨‍🌾 **農家** | 茶色 | 小麦×18、生肉×8 | パン・りんご・種・焼いた肉・金のりんご |
| 📚 **司書** | 白 | 糸×12 | **エンチャントの本**（家ごとに 4 種類。鋭さ5 なども）・本棚 |
| ⚒️ **鍛冶屋** | 黒 | 石炭×14、鉄×5 | 盾・効率強化つき鉄のツルハシ・鋭さつきダイヤの剣・ダイヤのツルハシ・ダイヤのよろい |

- 📕 **エンチャントの本**: 作業台のマスに、**本と道具を並べる**と、本の力が道具につきます（経験値はいりません）。本どうしを並べると、力を合わせた 1 冊になります。
- 🔔 **鐘**を右クリックすると、村人の人数と、次の赤い月がいつかがわかります。
- 鍛冶屋の家には**チェスト**があります。

### 🔴 赤い月の夜は、村もおそわれる
- 赤い月の夜、敵は**村人もねらいます**。村人は逃げますが、やられると**いなくなってしまいます**。
- 赤い月の夜に**村のそばに 45 秒以上いて**、朝まで生きのびると「**村を守った！**」。村人から**エメラルドとパン**のお礼がもらえます（たおした敵が多いほどエメラルドが増える）。
- **見つけたことのある村を守らなかった**ときは、朝に村人が 1 人へります。
- いなくなった村人は、**ふつうの朝が来るたびに 1 人ずつもどってきます**（新しい人が引っこしてくる）。

## 🌀 異世界（ネザー）
**黒曜石のわく**を組んで、**火打ち石**で中に火をつけると、むらさきに光るゲートが開きます。
中に入って **1.2 秒**まつと、向こうの世界へ移ります。

### 行きかた
1. **溶岩の源に水をかけて黒曜石を作る**（バケツの水を直接かけてもよい）。黒曜石は**ダイヤのツルハシ**でしか掘れません（約4秒）。
2. 黒曜石を **10 個**使って、たて長のわくを組みます。**内がわが 横2マス・たて3マス**になるように立てます。
   （内がわは 横2〜4・たて3〜5 マスなら何でもOK。角の4つは無くてもかまいません）
3. **火打ち石**（鉄 1 + 石炭か木炭 1 でクラフト）を持って、わくの内がわに向けて**右クリック**。
4. むらさきのうずまきが出たら成功。中に入って待ちましょう。

### 異世界のようす
- **太陽がありません。**朝が来ないので、敵は燃えて消えません。どこでも敵が湧きます。
- 上にも**岩盤のふた**があり、横に広い大きな洞窟が 1 枚ひろがっています。
- **地獄の石**（赤い石。すぐ掘れる）でできていて、低いところには**溶岩の海**がたまっています。**落ちたら大ダメージです。**
- 天井から**光る石**（明かりになるブロック）のかたまりがぶら下がっています。
- 床にはときどき**たましいの砂**があります。
- **ベッドは使えません。**異世界で倒れると、表の世界の復活地点にもどります。
- 💨 **水は使えません。**あつすぎて、バケツの水を置いたとたんに蒸発します。
- 👹 **異世界だけの敵**が出ます（下の「異世界の敵」）。表の世界の敵より、ずっと強いです。

### 異世界の なぞの建物
探検していると出会います。中に入ると「見つけた！」と出て、**マップに印**がつきます。数は 321×321 のワールドのとき（161×161 では 4 分の 1）。

| 建物 | 中身 |
| :--- | :--- |
| 🏯 **地獄のとりで**（4つ） | ネザーレンガの大広間から、4方向に長い橋がのびている。まん中に**ブレイズの湧くかご**、チェスト2つ（金・ダイヤ・黒曜石・ブレイズロッドなど） |
| 🏴 **黒い砦**（4つ） | ブラックストーンの**3階建て**。はしごで上へ。1階に**ゾンビピグリンの湧くかご**。各階にチェスト、**いちばん上の「宝の間」**（金の床）に良い宝（ダイヤの剣・よろい・ツルハシが出ることも） |
| 🌀 **こわれたゲート**（8つ） | 黒曜石のわくが、ところどころ欠けている。そばのチェストに**黒曜石と火打ち石**（直せば帰り道になる） |

- 黒い砦のかべには、ときどき**金まじりのブラックストーン**があり、掘ると金が出ます。

### もどりかた
入ってきたゲートに、もう一度入れば表の世界にもどります。
ゲートから出るまでは、もう一度飛ばされません（ゲートの中でつっかえません）。
向こう側にゲートが無いときは、**安全な場所をさがして自動でゲートを建てます**（溶岩の上には出ません）。

> 表の世界と異世界は、**それぞれ別に覚えています**。置いたブロックもチェストの中身も、
> 行ったり来たりしても消えません。マップも世界ごとに分かれています。

## 🌌 天空の島と最後のドラゴン
ボスを倒していくと、最後に**3 つ目の世界「天空の島」**へ行けます。そこには**最後のドラゴン**が待っています。

### 行きかた
1. **天空の目**を作ります（クラフト。形は自由）: **ブレイズパウダー＋ドラゴンのうろこ＋星のかけら → 天空の目 ×2**

## 🎒 持ち物とカバン

### ⛏️ 掘るのにかかる時間
- ブロックは**左クリックを押している間だけ**掘り進みます。途中で離したり、別のブロックを見たりすると最初からです。
- かたいブロックほど時間がかかり、**良いツルハシを手に持っているほど速く**なります（素手だと石は掘れません）。掘っている途中で持ちかえても速さが変わります。
- 掘っているブロックには、**だんだん深くなるひび**が入るので、あとどれくらいかが分かります。
- 草むらや花、松明などはすぐ取れます。
