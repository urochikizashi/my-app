# 3D Minecraft Web (Three.js MVP)

HTML5 / CSS / JavaScript と [Three.js](https://threejs.org/) を使用して作成された、ブラウザ上で動作する3Dボクセルクラフトゲーム（マインクラフトMVP）です。外部画像ファイルなどの外部依存なし（テクスチャやSEはプロシージャル生成）で単一のHTMLファイルで動作します。

## 🎮 操作方法

| キー / 操作 | アクション |
| :--- | :--- |
| **画面クリック** | ゲーム開始・マウスロック |
| **W, A, S, D** / 矢印キー | 前後左右に移動 |
| **SPACE** | ジャンプ |
| **マウス移動** | 視点回転（一人称FPS視点） |
| **左クリック** | **敵を攻撃！** (またはブロックを掘って持ち物に入れる) |
| **右クリック** | 持っているブロックを照準面に置く |
| **数字キー 1〜8** / **ホイール** | 持ち物の切り替え |
| **E** | クラフト画面を開く |
| **ESC** | 一時停止（マウスロック解除） |

## 🧟 敵モブ (Enemies)
- **クリーパー (Creeper)**:
  - プレイヤーに近づくと白く点滅・膨張しながら「シューッ」と起爆カウントダウン！
  - 時間内に倒すか逃げないと**大爆発を起こし、周囲の地形を消滅**させて大ダメージを与えてきます。
- **ゾンビ (Zombie)**:
  - 両手を伸ばして追いかけてきて、接近すると噛みつき/パンチ攻撃をしてきます。
- **出てくる場所**: 敵は**暗いところ**にだけ出てきます。
  - **夜の地上**: プレイヤーから少し離れた地表に出現。最初は3体で、4体倒すごとに同時に出てくる敵が1体増えます（最大8体）。
  - **暗い地下**（地面から5m以上もぐった場所）: プレイヤーの近くの洞窟やトンネルに出現。深いほど数が増えます（最大6体）。
  - **昼の地上**には出てきません。朝になると、明るい場所にいる敵は燃えて消えます。
- **深いほど強い**: 深い場所で出てきた敵ほど、体力（最大3倍）・攻撃力（最大2倍）・速さが上がり、体が大きく赤っぽくなります。
- 遠く離れた敵や、長いあいだプレイヤーに近づけない敵は消えて、また新しく出てきます。
- **自然回復**: 6秒間ダメージを受けなければ、少しずつハートが回復します。復活直後は3秒間無敵です。

## ⛏️ 地下探検
- 地面は地下40mまで続いており、最下層には壊せない**岩盤**があります。
- 地下には毎回ランダムに生成される**洞窟**（曲がりくねったトンネルや広い空洞）があり、地表にいくつか入口が開いています。洞窟の壁には鉱石が露出していることも。
- 深く掘るほど貴重な鉱石が見つかります: **石炭** → **鉄** (-6m〜) → **金** (-18m〜) → **ダイヤ** (-28m〜)
- 地下に潜ると暗くなり、手元のたいまつ光で周囲が照らされます。
- 画面左上に現在の深さ・最深記録・採掘した鉱石の数が表示されます。

## ☀️ 昼と夜
- 1日は5分（昼 約3分 + 夜 約2分）。新しいワールドは朝から始まります。
- 夜になると空が暗くなり、手元のたいまつ光がともります。画面左上に「夜まで / 朝まで」の残り時間が出ます。

## ⚔️ 戦闘システム
- **ハートゲージ (HP)**: 画面下に10個のハート（20HP）。ダメージを受けると減少します。
- **武器**: 最初は素手（攻撃 3）。クラフトで剣を作ると強くなります。敵を吹き飛ばします（ノックバック）。
- **効果音**: 起爆音、爆発音、攻撃ヒット音、プレイヤーの被ダメージ音などを完全自己生成。

## 🎒 持ち物とクラフト
- 持ち物（画面下の8枠）は**最初は空っぽ**です。ブロックを掘ると持ち物に入り、右クリックで置くと1個減ります。1枠に99個まで。
- 鉱石（石炭・鉄・金・ダイヤ）は画面左上の数に入り、クラフトの材料になります。
- **E キー**、一時停止画面、または**作業台を右クリック**でクラフト画面が開きます。
- まずは木材4個で**作業台**を作って置きましょう。剣やレンガ・ガラスは、**作業台の近く（横4マス・上下3マス以内）**でないと作れません。

| 作るもの | 材料 | 作業台 | 攻撃力 |
| :--- | :--- | :--- | :--- |
| 作業台 | 木材 ×4 | 不要 | — |
| 木の剣 | 木材 ×3 | 必要 | 5 |
| 石の剣 | 石 ×3 | 必要 | 7 |
| 鉄の剣 | 鉄 ×3 | 必要 | 10 |
| ダイヤの剣 | ダイヤ ×3 | 必要 | 14 |
| レンガ ×4 | 土 ×2 + 石炭 ×1 | 必要 | — |
| ガラス ×4 | 石 ×2 + 石炭 ×1 | 必要 | — |

- 置けるブロック: 草 / 土 / 石 / 木材 / 葉 / レンガ / ガラス / 作業台（作業台は掘れば持ち物に戻ります）

## 💾 セーブ
- ブラウザ（localStorage）に自動保存されます: **ESCで一時停止したとき**、**30秒ごと**、**ページを閉じるとき**。
- 一時停止画面の「💾 セーブ」ボタンで手動セーブ、「🆕 新しいワールド」でセーブを消して新しい地形から始められます。
- 保存されるもの: 地形（シード＋掘った/置いたブロック）、位置と向き、体力、持ち物、鉱石の数、撃破数、最深記録、時刻（昼/夜）。敵は保存されず、再開時に新しく湧きます。
- テスト用に、URL の最後に `?debug` を付けるとブラウザのコンソールから `game` でゲームの中身を触れます。
